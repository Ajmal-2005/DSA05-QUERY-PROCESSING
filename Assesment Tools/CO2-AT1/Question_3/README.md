# Question 3 - Employee and Department Database Design

## Objective
Store employee and department details with relational mapping using SQL JOIN.

## Files Included
- `q3.py` - Python program for employee-department database
- `company.db` - SQLite database file (generated after execution)
- `input.txt` - Sample input data used
- `output.txt` - Console output after execution
- `ER_Diagram.png` - Entity-Relationship diagram
- `README.md` - This file

## Requirements
- Python 3.x
- sqlite3 (built-in Python module)

## How to Run
```bash
python q3.py
```

## Expected Output
- Department and Employee tables created with foreign key relationship
- Employee names displayed alongside department names using INNER JOIN
