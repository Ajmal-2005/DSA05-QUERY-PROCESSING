# Question 5 - Online Course Registration System

## Objective
Manage student course registrations with relational tables and SQL JOIN queries.

## Files Included
- `q5.py` - Python program for course registration system
- `course_registration.db` - SQLite database file (generated after execution)
- `input.txt` - Sample input data used
- `output.txt` - Console output after execution
- `ER_Diagram.png` - Entity-Relationship diagram
- `README.md` - This file

## Requirements
- Python 3.x
- sqlite3 (built-in Python module)

## How to Run
```bash
python q5.py
```

## Expected Output
- Student and Course_Registration tables created with foreign key relationship
- Student names displayed alongside registered courses using INNER JOIN
