# Question 8 - Course and Faculty Management System

## Objective
Manage university faculty and course assignments using relational tables and SQL JOIN.

## Files Included
- `q8.py` - Python program for faculty-course management
- `university.db` - SQLite database file (generated after execution)
- `input.txt` - Sample input data used
- `output.txt` - Console output after execution
- `ER_Diagram.png` - Entity-Relationship diagram
- `README.md` - This file

## Requirements
- Python 3.x
- sqlite3 (built-in Python module)

## How to Run
```bash
python q8.py
```

## Expected Output
- Faculty and Course tables created with foreign key relationship
- Faculty names displayed with assigned courses using INNER JOIN
