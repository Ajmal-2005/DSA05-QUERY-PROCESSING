# Question 4 - Hospital Patient Database

## Objective
Manage hospital patient information with full CRUD operations using SQLite.

## Files Included
- `q4.py` - Python program for patient database operations
- `hospital.db` - SQLite database file (generated after execution)
- `input.txt` - Sample input data used
- `output.txt` - Console output after execution
- `ER_Diagram.png` - Entity-Relationship diagram
- `README.md` - This file

## Requirements
- Python 3.x
- sqlite3 (built-in Python module)

## How to Run
```bash
python q4.py
```

## Expected Output
- Patient table created with 5 records
- Contact number updated for a patient
- Discharged patient record deleted
- Remaining records displayed
