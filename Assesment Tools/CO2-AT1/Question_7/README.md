# Question 7 - Inventory Management System

## Objective
Maintain retail product inventory, identify low-stock items, and restock them.

## Files Included
- `q7.py` - Python program for inventory management
- `inventory.db` - SQLite database file (generated after execution)
- `input.txt` - Sample input data used
- `output.txt` - Console output after execution
- `ER_Diagram.png` - Entity-Relationship diagram
- `README.md` - This file

## Requirements
- Python 3.x
- sqlite3 (built-in Python module)

## How to Run
```bash
python q7.py
```

## Expected Output
- Product table created with 7 records
- Low-stock products (quantity < 10) identified
- Low-stock products restocked
- Updated inventory displayed
