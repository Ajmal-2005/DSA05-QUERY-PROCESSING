# Question 10 - Hospital Appointment Management System

## Objective
Manage hospital doctor and appointment records using relational tables and SQL JOIN.

## Files Included
- `q10.py` - Python program for hospital appointment system
- `hospital_appointments.db` - SQLite database file (generated after execution)
- `input.txt` - Sample input data used
- `output.txt` - Console output after execution
- `ER_Diagram.png` - Entity-Relationship diagram
- `README.md` - This file

## Requirements
- Python 3.x
- sqlite3 (built-in Python module)

## How to Run
```bash
python q10.py
```

## Expected Output
- Doctor and Appointment tables created with foreign key relationship
- Doctor names displayed with appointment details using INNER JOIN
