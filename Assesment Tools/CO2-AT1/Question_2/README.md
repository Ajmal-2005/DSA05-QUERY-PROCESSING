# Question 2 - Library Management Database

## Objective
Maintain library book information using SQLite with CRUD operations.

## Files Included
- `q2.py` - Python program for library database operations
- `library.db` - SQLite database file (generated after execution)
- `input.txt` - Sample input data used
- `output.txt` - Console output after execution
- `ER_Diagram.png` - Entity-Relationship diagram
- `README.md` - This file

## Requirements
- Python 3.x
- sqlite3 (built-in Python module)

## How to Run
```bash
python q2.py
```

## Expected Output
- SQLite database `library.db` is created
- Book table with 5 records is created
- Price of a selected book is updated
- Records displayed before and after the update
