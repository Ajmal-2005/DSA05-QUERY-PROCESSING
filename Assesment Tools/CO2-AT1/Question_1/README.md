# Question 1 - Student Database Design and Connectivity

## Objective
Automate college student record management using SQLite database with Python.

## Files Included
- `q1.py` - Python program for student database operations
- `student.db` - SQLite database file (generated after execution)
- `input.txt` - Sample input data used
- `output.txt` - Console output after execution
- `ER_Diagram.png` - Entity-Relationship diagram
- `README.md` - This file

## Requirements
- Python 3.x
- sqlite3 (built-in Python module)

## How to Run
```bash
python q1.py
```

## Expected Output
- SQLite database `student.db` is created
- Student table is created with 5 records
- All records are displayed in tabular format on the console
